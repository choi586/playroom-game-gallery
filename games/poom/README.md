# 품 — 섬마을의 닷새

경희대학교 글로벌류큐·오키나와연구소의 교육용 웹게임 데모입니다. 설치 없이 브라우저에서 열립니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 틀과 스타일 |
| `engine.js` | 게임 엔진(이동, 그리기, 날씨, 저장, 소리) |
| `scenarios/*.js` | 섬별 이야기. **글만 고치면 게임 내용이 바뀝니다** |
| `sw.js`, `manifest.webmanifest`, `icon.svg` | 오프라인 캐시와 홈 화면 추가 |
| `tests/smoke.py` | 세 편을 끝까지 자동으로 플레이하는 점검 스크립트 |

## 시나리오 고치기·새로 만들기

`scenarios/jeju.js`를 복사해 이름을 바꾸고, `index.html` 아래쪽에 `<script src="scenarios/새파일.js"></script>` 한 줄을 추가합니다. 오프라인 캐시에도 넣으려면 `sw.js`의 `FILES`에 경로를 더하고 `VERSION` 숫자를 올립니다.

| 항목 | 내용 |
|---|---|
| `key` | 영문 고유 이름 |
| `theme` | 그림 테마. `jeju`(초가·돌담), `oki`(붉은 기와), `tw`(벽돌집·산) 중 하나 |
| `label`, `short`, `emoji`, `color` | 첫 화면 버튼 |
| `year`, `intro` | 시대 표기와 도입 글 |
| `days` | 첫날~넷째 날 아침 글 4개 |
| `ch` | `[null, 선택, 선택, 선택]`. 선택 하나는 `t`(제목), `q`(상황), `a`(선택지 2개), `r`(결과 2개) |
| `amb` | 날마다 이웃 머리 위에 뜨는 짧은 말 |
| `nb` | 이웃 4명. `id`는 `g`, `d`, `m`, `b` 순서 고정. 각자 `st`(이야기) 3편, 이야기의 `w`는 `words`의 낱말 열쇠 |
| `stormOk`, `stormNo`, `ok`, `fail` | 태풍 장면과 그 밤 |
| `after`, `nowCap`, `rev` | 그 뒤의 이야기, 오늘의 장면 설명, 역사 해설 |
| `words` | 섬말 수첩. `열쇠: [낱말, 뜻]` |

형식이 틀리면 게임이 멈추지 않고 첫 화면에 무엇이 빠졌는지 표시됩니다.

## 수업에서 쓰기

- 주소 끝에 `#teacher`를 붙이면 다섯째 날(태풍)부터 시작하는 시연 버튼이 나옵니다.
- 하루가 시작될 때마다 그 기기에 자동 저장되고, 첫 화면에서 이어서 할 수 있습니다. 서버로 보내는 정보는 없습니다.
- 엔딩의 "내 결과 복사"로 들은 이야기와 선택을 글로 복사해 모둠 토론에 쓸 수 있습니다.
- 한 번 연 뒤에는 인터넷이 끊겨도 열립니다(글꼴만 기본 글꼴로 바뀔 수 있습니다).

## 점검

```
pip install playwright && playwright install chromium
python3 -m http.server 8000 &
python3 tests/smoke.py http://localhost:8000/
```

등장인물과 마을은 창작이며, 역사적 배경 서술과 섬말 표기는 전공 연구진의 검토를 거쳐 보완할 예정입니다.
